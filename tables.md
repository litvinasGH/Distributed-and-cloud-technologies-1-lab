## 3. Таблица сравнения работы без транзакции и с транзакцией

| Критерий                         | Без транзакции                                | С транзакцией                                           |
| -------------------------------- | --------------------------------------------- | ------------------------------------------------------- |
| Несколько связанных операций     | Выполняются отдельно                          | Выполняются в рамках одной транзакции                   |
| Атомарность                      | Не гарантируется                              | Гарантируется                                           |
| Возможность частичного изменения | Возможна                                      | Отсутствует при корректном выполнении`ROLLBACK`         |
| Использование`COMMIT`            | Не используется                               | Используется для фиксации успешных изменений            |
| Использование`ROLLBACK`          | Не используется                               | Используется при ошибке                                 |
| Сохранение изменений при успехе  | Каждая успешная операция сохраняется отдельно | Все связанные изменения сохраняются после`COMMIT`       |
| Отмена изменений при ошибке      | Автоматически не выполняется                  | Выполняется отмена изменений транзакции                 |
| Согласованность результата       | При ошибке возможно некорректное состояние    | Связанные изменения сохраняются целиком либо отменяются |
